# E HUD

E HUD is a context-sensitive information and diagnostics HUD for Minecraft Java Edition.

Version-specific Fabric builds are produced for Minecraft Java 1.21 through 1.21.11,
plus 26.1 and 26.2. Always use the jar whose filename exactly matches Minecraft.

## Development

The 1.21 builds use Java 21. Minecraft 26.1 and 26.2 use Java 25 and Fabric's
unobfuscated toolchain. Mod Menu is optional; without it, E HUD remains available
from Minecraft's Options screen.

The source package contains separate `1.21.x` and `26.x` build trees so each toolchain
can be reproduced without destabilizing the other.
